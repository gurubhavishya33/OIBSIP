# Personal Portfolio Website

## 📌 Project Overview

This is a personal portfolio website created as part of the Oasis Infobyte Web Development and Designing Internship.

The portfolio showcases my introduction, skills, projects, and contact information through a modern and responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Floating navigation bar
- Responsive design
- Hero section with introduction
- Interactive profile card
- Click-to-flip profile card
- Skills section with hover animations
- Project cards with hover effects
- Contact section
- Smooth scrolling navigation
- Custom cursor
- Responsive layout for different screen sizes
