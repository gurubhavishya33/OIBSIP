# VibeX – Music Discovery Landing Page

## 📌 About the Project

VibeX is a modern and responsive music discovery landing page designed for music lovers.

The website allows users to explore trending music, featured artists, and mood-based playlists through a clean and attractive interface.

## 🎯 Objective

The objective of this project is to create a professional landing page using HTML5 and CSS3 with a responsive design.

## ✨ Features

- Responsive navigation bar
- Attractive hero section
- Trending music section
- Featured artists section
- Mood-based playlist section
- Call-to-action section
- Responsive design for mobile and desktop
- Smooth navigation between sections
- Modern dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
