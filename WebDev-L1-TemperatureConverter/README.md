# Temperature Lab – Temperature Converter

A clean and responsive temperature converter website built using HTML5, CSS3, and Vanilla JavaScript.

## Project Overview

This project allows users to enter a temperature, select the input unit, and instantly convert the value into Celsius, Fahrenheit, and Kelvin.

The application also validates the input and prevents temperatures below absolute zero.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Convert between Celsius, Fahrenheit, and Kelvin
- Input validation
- Absolute zero validation
- Instant conversion results
- Responsive design
- Clean and modern user interface
- Mobile-friendly layout

## Temperature Conversions

- Celsius → Fahrenheit and Kelvin
- Fahrenheit → Celsius and Kelvin
- Kelvin → Celsius and Fahrenheit
